# Installation
See README "Quick start". Env vars actually used — backend: `NODE_ENV, PORT, SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY, FRONTEND_URL`. Frontend: `VITE_API_URL, VITE_SUPABASE_URL, VITE_SUPABASE_ANON_KEY, VITE_ROUTING_PROVIDER_URL, VITE_ROUTING_PROFILE`.
The backend refuses to start with a clear message if required variables are missing.
